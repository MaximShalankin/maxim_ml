# BERTScore vs Косинус: Ищем похожие доклады на конференции 🧐

Этот проект — простой эксперимент о том, как подготовиться к конференции и не повторить чужой доклад. Сравниваем два популярных метода поиска похожих текстов: быстрый **косинус** и "вдумчивый" **BERTScore**.

## Зачем это нужно? 🤔

Готовился к выступлению и столкнулся с двумя проблемами любого спикера:

1. **Быть уникальным** 💎: Найти похожие доклады, чтобы не повторять то, что уже рассказали до тебя.
2. **Найти "своих" для нетворкинга** 🤝: Заранее знать, с кем будет интересно пообщаться на смежные темы.

## Что я сделал? 👨‍🔬

Взял названия и описания всех докладов с конференции и сравнил их со своим, используя два подхода:

* 🚀 **Косинусная близость**: Очень быстрый метод. Находит тексты с похожими словами, но может упустить смысл.
* 🧠 **BERTScore**: Работает медленнее, но гораздо умнее. Понимает контекст и находит семантически близкие идеи, даже если слова разные.


## Что получилось? 📊

Главный сюрприз: методы нашли **разные** "похожие" доклады!

График ниже показывает, что топ-5 от каждого метода почти не пересекаются. Это значит, что "быстрый" и "умный" поиск видят релевантность по-разному.

## Главный вывод 🔥

Это классическая дилемма в RAG-системах: **скорость 🚀 vs глубина 🧠**.

* **Косинус** хорош для быстрого, первого отбора.
* **BERTScore** идеален для глубокого анализа и поиска неочевидных связей.

Идеальный вариант — использовать их вместе: косинусом быстро найти кандидатов, а BERTScore — выбрать из них самых лучших.
