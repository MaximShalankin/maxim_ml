# Python Telegram Tinder Game Bot
### What can I use this bot for? 
- The initial implementation was used for educational purposes. I use it to estimate students' EDA images.

### Known bugs in this version:

- Double statistics of images in ```image_stats.json```.
- Sometimes, the user log file writes empty ```name_left``` and ```name_right```.
- After a user session, the bot does not remove the last incomplete estimation.
- The log file writes ```choice``` with a space.
